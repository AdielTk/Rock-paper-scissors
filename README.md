# 🎲 Dicee

A simple dice game built with HTML, CSS, and vanilla JavaScript. Two players
roll a die each time the page is refreshed, and the winner is shown in the heading.

## Features

- Random dice roll for two players on every page load
- Winner (or draw) displayed automatically
- Dice images swapped dynamically with JavaScript DOM manipulation

## Built with

- HTML5
- CSS3
- JavaScript (DOM manipulation, `Math.random()`)

## How to run

1. Clone the repo: git clone https://github.com/AdielTk/dicee.git

2. 2. Open `index.html` in your browser.
3. Click on the Roll again button to roll again.

   ## Demo

[Live demo]-(https://AdielTk.github.io/dicee/)

## What I learned

- Selecting elements with `querySelector` and `querySelectorAll`
- Changing attributes and text with JavaScript
- Using `Math.random()` and `Math.floor()` to generate random numbers
- Layout with CSS (`inline-block` / flexbox)
